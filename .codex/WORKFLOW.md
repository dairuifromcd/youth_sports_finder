# Basketball V2 — 风险驱动工作流

目标：Fast Delivery + Repeatable Automation + Practical Data Quality。
范围与数据原则见 [AGENTS.md](../AGENTS.md) 和 [V2 Scope](../docs/V2-SCOPE.md)。
V1 任务历史仅作参考，不自动成为 V2 验收要求。

## 选择最小充分流程

| 任务类型 | 流程 | 必要证据 |
| --- | --- | --- |
| Simple Task | Main → Implementation → Relevant Tests | 范围核对、相关检查与结果 |
| Data Pipeline | Implementation → Real Data Sample → Basic Data QA | 真实样本来源、运行摘要、坐标精度、异常输出与重复运行结果 |
| High-Risk Data Change | Developer → Independent QA | 独立检查身份/训练关系、匹配规则、批量影响与回归风险 |
| UI Task | Implementation → Tests → Browser UAT（需要时） | 相关测试；需要 UAT 时保留真实交互与视觉证据 |
| Publication | Public Data Check → Owner Authorization → Authorized Publication | 来源许可、隐私、秘密/原始数据排除、拟发布产物及明确授权 |

Main 先确认当前批准任务、风险、验收标准、允许文件和权限，再选流程。
仅在需要时调用 Subagents，不强制每项任务经过 Developer、QA、UAT。
高风险包括身份合并、训练关系推断、坐标规则放宽或大批量公开数据替换。
独立 QA 不由实现者自测替代；发现缺陷只做相关修复与复验，默认最多三轮。
权限阻塞或三轮后仍失败则报告，不降低验收标准或擅自启动后续任务。

## 角色与真实结果

- Developer：简单端到端实现、自动化、相关自检。
- QA：按风险独立验证核心正确性、来源、精度与可重复运行；不编辑产品或验收要求。
- UAT：仅在 UI 任务需要时，独立操作真实浏览器并保存证据；不编辑产品或验收要求。
- 自定义角色以实际可用的 agent type 为准，不用普通子代理改名冒充加载。
- 未加载时如实说明；低风险任务可用当前会话能力完成，不为此修改全局信任或配置。
- 角色继承父会话权限；不编辑指令不是独立技术只读隔离。
- 项目内保存必要证据，避免覆盖旧记录；报告被测版本及实际命令/结果。
- Pass / Fail / Not Verified 必须有实际依据；未执行检查不报 Pass。

## Sandbox 与授权

- 所有操作受当前 Sandbox、工具访问控制和审批策略约束；文档不改变运行时权限。
- 仅修改授权项目与文件，不影响 V1、全局配置或无关资源。
- 项目外影响（含服务器、浏览器、缓存、临时文件及网络资源）先核对已有明确授权。
- 超出授权时，说明具体操作、资源、项目外影响、风险、恢复方法和安全替代方案，获批后才执行。
- Owner 授权不替代工具运行时审批；审批拒绝时停止相关操作并保留实际错误。
- 不关闭安全保护、不更改全局策略、不切换工具绕过拒绝，不自动安装缺失依赖。
- 未明确授权不得 Commit、Push、Deploy、对外发布或使用付费服务。

## 浏览器 UAT 与安全收尾

1. Main 确认授权覆盖目标 URL（协议、主机、端口、路径）、操作、截图位置和项目外影响。
2. 使用已授权的可用工具与隔离测试会话，仅访问指定目标，不访问个人标签或无关项目。
3. 实际操作相关桌面/移动交互并查看截图；DOM、Console、Network 仅作补充。
4. 工具或审批阻塞时停止新测试，记录错误及 Not Verified；不通过换工具绕过审批。
5. 操作及必要截图完成后，优先关闭已确认归属本轮的测试会话，保存目标与实际返回，再整理报告。
   使用项目 `ysf_browser` 时调用 `browser_close`；其他已授权工具按其关闭机制及安全收尾要求执行。
6. 即使业务测试失败，已建立会话在授权内且安全、工具可用、可受控中断时仍须尝试关闭。
   不为收尾新建会话；无法安全关闭时记录原因并停止，不扩大权限。
7. 有总时间窗口时，在总预算内为关闭及确认预留至少 20 秒；每次操作前检查余量。
   进入预留时段立即停止新测试；关闭调用须有短时上限，仍受总硬截止约束，不超时追加。
8. 关闭失败、中断、无返回或无法尝试时保留错误，将关闭与清理标记 Not Verified。
   不因发送关闭请求、代理中断或业务通过就声称清理成功。
9. 仅关闭本轮测试会话，不用 `pkill Chrome` 等方式影响未知进程或个人会话。
   会话关闭与 MCP 服务退出分别判断，不强制杀服务，不从关闭返回推断所有缓存/临时文件已删除。
10. Main 独立核对目标归属和关闭实际返回，分别报告业务测试、关闭/清理及未完成项。
    缺少必需收尾证据时不得报告完整生命周期 Pass；复核也不得扩大授权范围。

## 交付

只报告本任务变更、相关检查、必要证据及剩余问题，不重复完整历史审计。
有当前任务 Implementation Result 时更新它，不重写 V1 历史记录。
完成后停止等待 Owner 验收；后续 Pipeline、发布或扩展需另有任务授权。
